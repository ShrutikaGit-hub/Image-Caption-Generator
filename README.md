# Image Caption Generator using CNN and LSTM

This project generates a meaningful text caption for an input image using deep learning. It uses InceptionV3 as a CNN-based image feature extractor and an LSTM network to generate captions word by word.

## Features

- Extracts image features using pretrained InceptionV3
- Uses LSTM for caption generation
- Trains on image-caption datasets such as Flickr8k
- Generates captions for new images
- Built with Python and TensorFlow/Keras

## Technologies Used

- Python
- TensorFlow / Keras
- CNN (InceptionV3)
- LSTM
- NumPy
- Pandas
- Pillow
